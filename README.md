# Bin Race 3 — Instaladores e atualizações

Baixe o instalador na [página de versões](https://github.com/maumau1902-bit/bin-race-3-releases/releases/latest).

Este repositório contém somente o canal público de instaladores, os arquivos de integridade e as instruções de publicação. O código-fonte do aplicativo permanece privado. Arquivos pessoais de telemetria não são publicados aqui.

No Windows, feche o aplicativo antes de instalar uma nova versão. Os treinos e detalhes ficam no perfil local.
